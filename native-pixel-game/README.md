# Native Pixel Adventure

Native Android 2D platformer demo built with Java + Canvas, no game engine dependency.

Features: touch controls, side-scrolling camera, animated pixel-art character, enemies, coins, pipes, goal flag, lives, score, level-clear/restart flow, and synthesized retro sound effects.

References:
- Kenney Platformer Art Pixel (CC0): https://kenney.nl/assets/platformer-art-pixel
- Pinterest level-map references were used only for general layout inspiration.

No Nintendo/Mario game assets, sounds, or artwork are redistributed.
