# Jungle Platformer

Native Android 2D platformer implemented with a custom Java Canvas renderer.

The visual scene is a hand-built recreation based on the supplied reference screenshot: teal jungle backdrop, floating grass platforms, palm trees, crates, chest, ladder, gems, coins, keys, signs and pickups.

Controls:
- Left/right circles: move.
- JUMP: jump.
- The game uses lightweight native physics and collision.
